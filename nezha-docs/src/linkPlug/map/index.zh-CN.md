# 注意事项
1. 开发时可以先参考examples找到对应的例子 再通过api查看详细设置
2. 地图样式支持配置 需要登陆 maptilerCloud 注册对应账号 即可查看
3. 修改样式可以在 cloud 编辑对应样式 左侧页面查看 之后保存对应的json
4. 注意引用时 新增一些图层可能需要新的外部文件
